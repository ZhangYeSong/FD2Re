G.F全称Guardian Force，意即守护圣兽，战斗中的作用异常强大。这里所介绍的G.F可以归纳为两大类。一类是正常作战中我方可自行召唤的常规G.F，另一类则是以自身意志或是道具形式出现的伪G.F，俗称特殊G.F。下面将针对这两种不同又别具特色的G.F的特点和入手方法分别进行报道和介绍。

特 殊 G.F

名称 Chocobo(陆行鸟)
简介
陆行鸟一向是最终幻想系列里的宠物和交通工具，在本作中则以单独的召唤兽身份登场，玩家可以在FF8配套的小游戏“Chocobo World”(陆行鸟世界)中对其进行培养，通过在陆行鸟世界中所遇到的某些事件可以培养出几种不同的召唤技，详见“陆行鸟世界”页。
召唤技 属性 效果
陆行鸟火焰(ChocoFire) 火 被召唤出来的小陆行鸟被敌人吓到，从口中吐出火焰，烧向敌人全体
陆行鸟核爆(ChocoFlare) 无 陆行鸟发射能源弹，在敌方中心地带爆炸，造成敌全体无属性伤害
陆行鸟陨石(ChocoMeteor) 无 陆行鸟召唤星型陨石，砸向敌人，造成敌全体无属性伤害
陆行鸟压顶(ChocoBocle) 无 陆行鸟召唤胖陆行鸟(DaveChocobo)压垮敌人，造成敌全体无视防御力的无属性伤害，伤害量可超过9999
取得方法
在陆行鸟森林找到陆行鸟妈妈后，第一次要骑陆行鸟出森林之前，陆行鸟男孩会交给你一只小陆行鸟(默认名字Boko)。在战斗中使用道具基蕯爾蔬菜(Gysahl Greens)即可以召唤陆行鸟。不过要注意一点，必须在SAVE画面-陆行鸟世界中选择了HOME一项，否则会因为陆行鸟出门而无法召唤。

名称 Mog(莫古)
属性 无
召唤技 Moogle Dance(莫古之舞)
简介
Mog跳着奇异的舞蹈，使所有处于结合中的GF HP全回复&复活。
Mog在最终幻想系列里一向是以飞天猪的姿态出现，但是在FF8里竟然以猫的模样登场了。
取得方法
在“Chocobo World”(陆行鸟世界)找到Mog后，在FF8中使用道具莫古护身符(Mog's Amulet)，让GF学会MiniMog能力，在战斗时使用该指令，即可以召唤出。需要注意两点：与陆行鸟一样，必须SAVE画面-陆行鸟世界中选择了HOME一项；另外的一点就是每次召唤Mog要耗费队伍平均等级×100Gil的钱，所以没有Gil也无法召唤。

名称 Moomba(蒙巴)
属性 无
召唤技 MoombaMoomba(蒙巴蒙巴)
简介
Moomba从天而降，对着敌人单体脚踢、爪抓、抛沙，然后迅速跑走。使敌单体受到“剩余HP-1”的伤害(9999为上限)，无视防御力。
Moomba是FF8中兽类角色戏份最多的，它的来历可不简单，与Shumi族有重大关系。
取得方法
在“Chocobo World”(陆行鸟世界)可找到道具友情的证明(Friendship)，在FF8中使用，便可以召唤了。

名称 Phoenix(不死鸟)
属性 火
召唤技 Rebirth Flame(转生之炎)
简介
大地碎裂，描绘出Phoenix的姿态，Phoenix从图案中飞起，使我方全体复活(回复最大HP的12.5%)，并造成敌全体火属性伤害。
Phoenix即是凤凰，其美丽的姿态无人能比。在本作中，当我方全灭时，会有一定几率随机召唤，复活全体，避免GAME OVER。有时一场战斗中也许会救我方数次。
取得方法
使用道具不死鸟之羽(Phoenix Pinion)即可以召唤，另外在全体战斗不能时随机也会随机召唤(不耗费不死鸟之羽)。



名称 Odin(奥丁)
属性 无
召唤技 Zantetsuken(斩铁剑)
简介
阴云密布，细雨朦胧，Odin骑着他的爱马出现，奔向敌人，斩—铁—剑，将敌人砍为两半。
Odin战斗开始时1/8几率出现，招数是即死攻击，不过除了对Seifer(第四次)的战斗，其他BOSS战Odin不会出现。
取得方法
在中央遗迹对战Odin，并且取胜。以后在战斗开始时随机召唤。



名称 Gilgamesh(吉尔盖美希)
简介
一道闪光划过，4把剑从天而降插入地面，Gilgamesh拿起其中一把(落在屏幕最里边的)对敌人挥砍。
Gilgamesh是FF5中的一个喜欢收集武器的人。本作中成为替代Odin的乱入型召唤兽。在战斗中乱入出现，启动最多的是斩铁剑。
武器 属性 来源及效果
Zantetsuken(斩铁剑) 无 Odin死后乘乱捡得，功能与Odin时一样，一击必杀。
Masamune(正宗刀) 无 FF7最终BOSS Sephiroth所用的长刀。在其死后乘乱捡得，可对敌人全体造成极大伤害。
Excaliber(艾克斯卡利巴之剑) 无 俗称石中剑、圣剑，从旧货摊中购得。可造成敌全体无属性伤害
Excalipoor(伪艾克斯卡利巴之剑) 无 假圣剑。从古董店花巨资买来的赝品。无视防御力，但只能造成敌HP-1
取得方法
在第三张牒末尾处对战Seifer(第四次)之前得到Odin，战斗开始时，Odin出现被Seifer所杀，之后经过一段时间或者Seifer的HP归0后，Gilgamesh出现。以后在战斗中随机召唤。
