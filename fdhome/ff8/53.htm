一些剧情事件会提高或降低SeeD经验值（评价分），大部分事件中的变化值是100（1级所需的经验值即100分），也就是整级整级的变，不过也有些事件影响小于100的经验值，这就是为什么完成某相同事件有时会提高SeeD等级而有时却不会的原因。

当SeeD等级为1时，降低经验事件无效果。当SeeD等级为A时，提高经验事件无效果。

任何剧情事件最多只能把SeeD经验提高到3100，尽管上限是3110。

下面是所有会影响SeeD经验的全部剧情事件。

（1） 展示武器

从炎之洞穴考试回来后，去2楼教室前的走廊，和左边的蹲在地上的男生交谈（此人随机出现），他会要求看看Squall的枪刃，如果同意，则Aka教官会出现并使Squall得到一顿臭骂。当完成SeeD资格考试后，等级自动下降1。

（此事件在出发去Timber前也可发生，但只能发生1次。）

（2） Balamb Gareden的校规

在成为SeeD的舞会开始直至到回学生宿舍休息这段期间，如果连续三次试图通过学校闸门的话，SeeD Rank就会下降1，而之後每次试图通过，SeeD Rank都会被扣1。

（3） 绑架大总统

在协助「森之猫头鹰」绑架大总统的任务中，完全没有被士兵看见，并成功交替列车的话，SeeD Rank就可以上升1，若是被看见10次以上，就会下降1个SeeD Rank。而被看见1至9次，SeeD Rank就会维持不变。

（4）无名王墓

在无名王墓中观看地图时，按下W键（取消键）返回入口的话，SeeD Rank就会下降1。

（5）导弹基地任务

如果圆满完成此任务，最好结果是SeeD等级上升2级。详细事件请参考图文攻略。

以下行为将影响到对此任务完美程度的评判：
 1- 被底层楼梯后的士兵要求传口信时，是否传达正确的口信
 2- 是否过早解除伪装而开打（在配电室或导弹仓库）
 3- 基地自爆时间限制的选择

以下行为不会影响评判：
 1- 第一次路过配电室门口士兵处的选择
 2- 破坏配电室机器面板的方法
 3- 取得控制台密码的士兵处的回答（如果过早解除伪装的话）
 4- 击倒BGH251F2后的剩余时间数

具体计算方法：
任务开始时，默认你有200分的初始分，如有任何不适当的行为都会导致扣分。在任务完成时，你会得到 [200-扣分总数] 数量的SeeD经验，如果扣分为0就能获得200点的SeeD经验，即等级上升2级。
 1- 传递错误的口信 = 扣7分
 2- 过早解除伪装（无论在配电室还是导弹仓库） = 扣105分
 3- 选择10分钟自爆 = 扣0分
 4- 选择20分钟自爆 = 扣15分
 5- 选择30分钟自爆 = 扣45分
 6- 选择40分钟自爆 = 扣75分
 7- 如果在上面多于两个地方被扣分，则会被附加扣掉3-8分

正确的行为：
 1- 传递正确的口信（第一项）
 2- 配电室选择让他们进去看（第二项）
 3- 导弹仓库选择帮忙（第一项）
 4- 自爆时间设定为10mins

完美完成任务后得到200点SeeD经验。

（6） 魔法违规

学园内乱时击败NORG后，在到达FH前，去学园的2楼教室前的走廊，能找到一个男孩，他会要求Squall用个魔法给他看看。如果答应，Squall会使用Blizzard魔法，Aka教官又会跑出来骂Squall一顿，然后SeeD等级下降1。

（7）FH的钓鱼老人

这个事件步骤较多，在第一次到达FH时，必须完成以下所有步骤：

 1．进入FH时，在到达升降梯以前，从那个不起眼的梯子爬下，到机械吊臂处，与钓鱼老人交谈并道歉，得到杂志Occult Fan III。

 2．再次交谈，老人会告诉你他的弟子在码头处，去码头（旅馆向右的地方），和渔船边的男孩交谈，选择“Sort of”，“I saw him”和“I was sort of…impressed”，然后男孩甩钓鱼线可是失败了，被武器店老板责骂。

 3．去市长家发展剧情，打退Galbadia军队后，再次找码头的小男孩，他会再次甩钓鱼线并且成功了，然后让你去告诉钓鱼老人。

 4．回机械吊臂处找钓鱼老人（Irvine会半路加入），老人会告诉你在旅馆见面。

 5．去工场找Grease Monkey，出去再进入得到Mega Phoenix。

 6．去旅馆2楼见钓鱼老人，老人会讲述一些FH的历史，然后选择跟着他走。

 7．跟随老人到码头，老人会和男孩、武器店老板对话。与武器店老板对话，得知一些FH的历史，最后钓鱼老人会交给你一个Megalixir。

完成以上事件后，可得到20点SeeD经验。

（8） Balamb封锁事件

在这个剧情中要找到Captain（就是雷神），有三种方法可以找到雷神。详见图文攻略。

时间过了：不得经验。
上火车找：得到65点SeeD经验。
利用小狗：得到100点SeeD经验。

在港口停车场花钱买线索和中途离开镇子不会影响SeeD经验。

（9） Shumi族之村的雕像

详见隐藏事件“Shumi族之村”

在完成找石头任务之后，可从长老处得到一个Phoenix Pinion。完成此事件可得到50点SeeD经验。

Shumi族之村剧情的后续发展不影响SeeD经验。

（10） 深海研究中心

深海研究中心位于大地图西南角，可取得两个强力GF。

击败Bahamut = 得到50点SeeD经验。

击败Ultima Weapon = 得到100点SeeD经验。

进入大海之沉淀的方法不影响SeeD经验。
