Java神作《苍神录》正式移植Android平台

来源：巴哈姆特　　作者：巴哈姆特　　日期：2014-1-19
分享到：

　　奥尔资讯17日宣布，旗下自主开发自制、于 2006 年发售的 JAVA 手机游戏《苍神录》已正式移植 Android 平台。

　　根据官方的游戏介绍，《苍神录》是以古代中国為背景的武侠风格 RPG 游戏，玩家将扮演男主角，经历一段错综纠葛的剧情。奥尔资讯表示，希望能透过这次的移植让玩家们能够再次体验到往日的作品。

　　《苍神录》是首款以 PC Game 规模开发的手机 RPG 游戏，浓厚中国风加上原创剧情，整体故事架构庞大，搭配华丽的视觉效果及憾动人心的音乐，更创新穿插 KUSO 恶搞剧情。

　　《苍神录》的故事发生在古代中国，商末周初之时，富正义感的男主角战廷云，在年幼时经历战乱，与青梅竹马歆儿逃跑时不慎跌落山谷后，由师父胤晨所拾回，并与女主角苏芷嫣一同长大。自小便身染异病的芷嫣，在一次协助村民的事件中，病情突然发作。为了根治芷嫣的病，廷云与芷嫣自此踏上旅途。

　　本作采用连续小说的方式来呈现游戏情境。以第一章为例，就让玩家有如看一场电影一般，了解男女主角从小到大的生活背景、酸甜苦辣点滴。

　　《苍神录》在 2014 年移植到 Android 系统，此次的重制版将十一个章回全整合在一起，让玩家能够完整地体验到这款游戏。

　　除此之外，在 2014 年奥尔资讯将以《苍神录》的时空背景及原班人马製作团队，打造一款复合型手机游戏《Project G》，加入更多变化与要素的剧情将带玩家一步一步了解“伏”所代表的真正意涵。游戏剧情内的种种跡象，究竟是顺应天命还是不知名的势力在背后运作？玩家们将在此获得解答。

　　《苍神录》目前已于 Google Play 商店上架，有免费版与付费版(150 元新台币)可供选择。（巴哈姆特）
