修改工具法: FPE v5.0

这里是用FPE 5.0 的修改方法及参数,依此类推, 从开始时数就对啦!很简单的!

##举例:
一开始全部人员未动时从F2看HP值:
例 : HP=255 输入255,00,255,00 (因 255 = FF )
例 : HP=256 输入257,257 (257 = 01 01 )

1.用ＦＰＥ扫描 SCAN MEMORY 输入 HP值
2.按 E 键 进入 EDIT MEMORY 编辑模式
3. 位置 Physical address : (004B5CE4)h

## 为物品栏 .　　　 我只建议E0光之徽章,E1的暗之徽章!
LV 为等级。　　　　 (你可以升到40级时在重升级一次喔且AP,DP会继续增加!) 。
MV 为MV值。　　　　 即移动格数，最好写成1A，往後随等级增加而会再增加，刚开始不可以写超过1A，否则程式会错乱喔!你将会发现超过半个地图都会笼罩在你的移动范围之下。
EX 为经验值。　　　 最好是写成 99=63h, 升完後再回来写成 99=63h
DX DX 为DX值。　　　直接修改即可，但不要写太大，以免变成负数。
HP HP HP HP 为HP值。前两个 HP HP 是现有的HP值
后两个 HP HP是总共有多少的HP值。
一样，不需写太大，大约 FF 50就打不死啦!!
MP MP MP MP 为MP值。分配法和HP值一样。
即使没有魔法者也可以修改使其有 MP 值。
再配合魔法的修改，便可使每个人都拥有超强魔法喔!
AP AP 为AP值。　　　可以修改，但是会随着等级的增加而变回原数值，所以最好的方法是将等级升到最满之後再修改。
(但往後每进入一场战役都会变回原来的数值)
DP DP 为DP值。　　　与HP值同。
HH HH 为HIT值。　　 只要修改一次即可保持，往後会随等级的增加而增加。
EV EV 为EV值。　　　与HIT同。

炎外代码

游戏可用FPE修改，但它的人物存储地址会变化，因此如果一次没找到，就只有重读记录再扫描一次。例如兰迪斯的生命值是450/512，魔法值是165/210，进入FPE，切换至WORD状态，键入450，512，165，210后回车，就找到生命值的地址。上面四行即是等级，物品栏和所会魔法等状态的地址。物品代码用两位表示，头一位用80表示没有物品，00表示有物品，40表示已装备物品，第二位为下面的物品代码。
