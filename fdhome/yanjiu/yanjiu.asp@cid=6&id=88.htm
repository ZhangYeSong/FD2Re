炎外全人物魔法和攻击技能分析

来源：汉堂之家　　作者：兰迪斯　　日期：2008-2-17
分享到：

前言：炎外是一款经典的ＳＲＰＧ，特别是其中的魔法和技能，但不同的转职路线学到的魔法都不相同，不少朋友在为如何转职发愁，下面我就分人物分职业把魔法和技能介绍一下，让朋友们可以找到自己心中最佳的转职路线。（魔法排列是按该职业学得的顺序。实用度和华丽度等级为Ｓ、Ａ、Ｂ、Ｃ、Ｄ，最高为Ｓ，最低为Ｄ，不同人物同一魔法的实用度和华丽度可能不同，实用度的评价范围为该人物学得此魔法的时期，不然初级魔法和高级魔法是无法比较的。）

兰迪斯

剑士

业火 实用度 B 华丽度 D
分析：最低级火系魔法，杀伤力较低，但在初期可以用来练级。但是兰初期魔法值不高，要多备些魔法草。

狂暴巨焰 实用度 B 华丽度 C
分析：第二级火系魔法，杀伤力仍然不高，比业火更容易练级，但命中率明显下降，使用前最好SAVE下。

烈狱之火 实用度 B 华丽度 B
分析：第三级火系魔法，杀伤力和命中率明显提高，比较实用的魔法。

剑圣

暴炎狂龙 实用度 B 华丽度 S
分析：顶级火系魔法，杀伤力较高（但和攻击技能的杀伤力是没法比的），后期兰基本不用出手，也就只能用来欣赏了。

剑帝

魔龙霸炎 实用度 A 华丽度 A
分析：剑帝兰迪斯的最强攻击技能，范围为直线7格的所有敌人，威力是1.2倍攻击力，威力在攻击技能里不算高，也不够华丽（就出来一只龙在喷火），除了打BOSS，其他时候也用不上，是个比较让人郁闷的技能。

暴炎狂龙 （同剑圣）

英雄

魔龙霸炎 （同剑帝）

暴炎狂龙 （同剑圣）

痊愈之泉 实用度 C 华丽度 C
分析：不到极其无奈的时刻，有人会让兰来补血么？不过倒是可以用来练级，这个技能也让英雄这个职业更加全面。

传送术 实用度 S 华丽度 A
分析：重头戏来了，炎外中英雄的两项得意技能之一。在2代中泛滥的传送术，在外传里显得尤其珍贵，抢宝物和位置就靠它了，强力推荐！

圣龙霸烈斩 实用度 S 华丽度 S
分析：英雄的最强得意技能，也是比较华丽的技能，范围为直线15格的所有敌人，2.5倍攻击力，这个技能可以让兰在很远就把最终ＢＯＳＳ干掉。唯一缺点是耗魔太多，要多带些水晶粒辅助了，强力推荐！

尤利安

僧侣

恢复之光　实用度 Ｂ 华丽度 Ｄ
分析：最低级恢复魔法，但是初期练级全靠它了，优点是耗魔少，缺点是补血范围和能力都很低，有时候会让人补不上血，只能干着急。

封魔咒术　实用度 Ｃ 华丽度　Ｄ
分析：基本上用不上的魔法，耗魔也比较高（初期），鉴于对一些ＢＯＳＳ是有效的（巫汤婆婆和死神等），可以用来虐待ＢＯＳＳ和练级，应该算是经常被人遗忘的辅助魔法。

治愈之风　实用度 Ｂ 华丽度 Ｄ
分析：第二级的恢复魔法，初期练级必备，耗魔也不多，比较不错的技能。

痊愈之泉　实用度 Ｂ 华丽度 Ｃ
分析：第三级的恢复魔法，中期练级的关键，没什么缺点，同样不错的技能。

大僧侣　

苏愈术　实用度 Ａ 华丽度 Ｃ
分析：后期敌人的状态攻击比较多，特别是几个ＢＯＳＳ的魔法都带状态攻击，中毒和封魔都可以忍了，但是麻痹怎么忍？所以此技能必不可少，推荐。

镇魂之歌　实用度 Ｂ 华丽度 Ａ
分析：最强的恢复魔法，同时也是最不实用的，耗魔也比较多，除非用来救重伤的人，不然不推荐这个鸡肋技能。

大祭司

光之箭　实用度 Ｂ 华丽度 Ｂ
分析：初级的光系攻击魔法，范围为8格内单体敌人，可以用来狙击敌人，缺点是威力太小，往往打不死人，比较遗憾。

神之祝福 实用度 S 华丽度 A
分析：最强的辅助魔法之一，超大十字范围，所有己方（包括NPC）的攻防速度*1.15，耗魔50也可以接受，更大的价值是用来练级，几次就可以到顶级了。

镇魂之歌 （同大僧侣，鸡肋技能）

圣光柱 实用度 A 华丽度 B
分析：第二级光系魔法，耗魔40显得多了点，但是威力还可以，比光之箭更容易狙击敌人，推荐。

苏愈术 （同大僧侣，推荐技能）

亚克

骑士（无）

圣骑士

痊愈之泉 实用度 B 华丽度 C
分析：圣骑士的唯一的一个技能，由于本身魔法值有限，只能用于救人，如果要用来练级的话，就要多买魔法水了。

大地骑士

强力冲击 实用度 A 华丽度 S
分析：这是亚克比较自豪的一个技能，攻击直线7格内所有敌人，威力是2.5倍攻击力，效果也比较华丽，但由于要使用个暗之徽章，经常要牺牲这个职业，所以看过这个技能的人很少，强力推荐炎龙迷看一下这个技能。

法莲娜

魔导士

落雷术 实用度 C 华丽度 D
分析：雷系的一级技能，威力和命中率都不高，也就范围比火系和冰系强点，只能用来骗骗经验。

麻痹术 实用度 A 华丽度 D
分析：这个技能算是辅助魔法里不错的了，可以把敌人麻痹，然后起到堵路的效果，用来练级和虐待BOSS都不错，就是命中率不高，使用时要多S/L几次。

奔雷弹 实用度 B 华丽度 C
分析：雷系的二级魔法，威力和命中率仍然不高，但其大范围可以用来在前期练级。

恢复之光 （不知道她学习这个技能有什么用？？）

暴雷绝击 实用度 B 华丽度 B
分析：雷系的三级魔法，威力终于展现了，但命中率已经成为了老大难问题，在练级时要多S/L才能达到理想的练级效果。

法师

治愈之风（可以适当补点血用，不过好象没什么意义）

光之箭 （同尤利安）

圣光柱（同尤利安）

痊愈之泉 实用度 B 华丽度 C
分析：终于学会有用的恢复技能了，后期练级必备，推荐使用。

审判之雷 实用度 B 华丽度 B
分析：雷系的顶级魔法，可是威力和命中率的问题始终得不到解决，连效果都很平庸，让人很难想象这是个顶级魔法。（强烈要求用审判之雷使用片头雷系魔法的效果！！！）

巫师

治愈之风（…………）

震空重力弹 实用度 C 华丽度 B
分析：除了距离远点，其他的还不如雷系的魔法，真怀疑这个魔法是用来凑数的。

审判之雷 （同法师）

超重力黑洞 实用度 B 华丽度 A
分析：这个技能应该在魔法中算是不错的了，距离远而且威力大，26章前都可以秒杀杂兵，效果也不错，推荐！

万神降临 实用度 A 华丽度 A
分析：法莲娜的最强攻击魔法，威力很大，效果很不错，强烈推荐各位一看。就是没什么用武之地，毕竟没法和攻击技能比啊。

裘娜

战士 （无）

狂战士

金刚斩 实用度 S 华丽度 A
分析：最强的单体攻击技能，威力为2.5倍攻击力，移动后可以使用，耗魔也不多，加上妖刀村正和正宗都可以补魔，相当于可以无限使用。能力达一定时，可以秒杀魔战将军泛拉沛。强烈推荐技能！

圣战士

金刚斩 （同狂战士，但由于自身攻击力的问题，效果可能不如狂战士）

费塔加

魔导士

冰暴术 实用度 C 华丽度 C
分析：第一级冰系魔法，但是由于已经会了二级，还有人会去用么？？（除非为了省魔或用一级魔法练级，但我宁愿用二级的练，因为MP只差10，但是在不杀死敌人的条件下得到的经验二级比一级会多很多。）

绝杀冰封 实用度 B 华丽度 C
分析：二级的冰系魔法，初期练级必备，但是练出了裂地术，就完成了使命（好悲壮……）。

裂地术 实用度 A 华丽度 B
分析：超级的练级魔法，用几次就能到顶级了，强力推荐技能，缺点就是耗魔比较多，多买点魔法水吧。

冰魔超速弹 实用度 B 华丽度 A
分析：三级的冰系魔法，华丽大于实用的技能，威力还可以，就是平常都用不上。

巫师

封神裂震 实用度 A 华丽度 A
分析：同样的练级技能，也比较华丽。但是耗魔同样让人郁闷，没办法，用魔法水吧。

极度冰冻 实用度 A 华丽度 S
分析：顶级的冰系魔法，也是很养眼的魔法，威力和命中率也很高，就是实际作用不大，但是推荐一看。

法师

光之箭 （同尤利安）

圣光柱（同尤利安）

极度冰冻（同巫师）

痊愈之泉 （推荐的恢复技能，不过小费好象用不着补血练级……）

神行术 实用度 S 华丽度 B
分析：超强的辅助技能，最多可以让5个人可以再行动一次，这个魔法体现出了小费的真正价值，打BOSS（或者说虐待BOSS）和练级都必备，强烈推荐！！！

机械大师

机兵
